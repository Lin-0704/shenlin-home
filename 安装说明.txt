  沈先生的家 · 第一间房（核心聊天）
  安装 & 运行说明（安卓 Termux）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

这间房能做什么：
  打开手机浏览器 → 跟沈秣一对一聊天 → 他的回复一个字一个字冒出来
  → 所有对话自动存在本地（data/messages.json）。

──────────────────────────────────────────
〇 你需要准备的两样东西
──────────────────────────────────────────
  1. 一个 Gemini API Key（去 Google AI Studio 免费申请）。
  2. 手机能连得到 Gemini（你平时挂的那个网络／VPN 开着就行）。

──────────────────────────────────────────
① 装 Termux
──────────────────────────────────────────
  从 F-Droid 安装 Termux（别用应用商店那个旧版本）。
  装好打开，是一个黑色的命令行界面。

──────────────────────────────────────────
② 在 Termux 里装 Node.js
──────────────────────────────────────────
  逐行输入下面的命令，每行回车，等它跑完：

      pkg update -y
      pkg install nodejs unzip -y

  装完输入这个验证，能看到版本号就成功：

      node -v

──────────────────────────────────────────
③ 把项目放进去
──────────────────────────────────────────
  把下载的 shenmo-chat.zip 放进手机后，在 Termux 里：

      # 先让 Termux 能读到手机存储（只需做一次，会弹授权）
      termux-setup-storage

      # 假设 zip 在「下载」文件夹，解压到主目录
      cd ~
      unzip ~/storage/downloads/shenmo-chat.zip

      cd shenmo-chat

──────────────────────────────────────────
④ 填上你的 API Key
──────────────────────────────────────────
  复制配置模板：

      cp config.example.json config.json

  用编辑器打开填 Key（nano 是自带的小编辑器）：

      nano config.json

  把 "apiKey" 那一行引号里的字，换成你的真实 Key。
  改完按 Ctrl+X，再按 Y，再回车，保存退出。

──────────────────────────────────────────
⑤ 安装依赖 & 启动
──────────────────────────────────────────
      npm install        # 第一次要等一会儿
      npm start

  看到「沈先生的家 已启动 🏠」就成功了。

──────────────────────────────────────────
⑥ 开聊
──────────────────────────────────────────
  保持 Termux 开着，打开手机浏览器，地址栏输入：

      http://localhost:3000

  就能看到聊天界面，给沈先生发消息吧。

──────────────────────────────────────────
※ 常见问题
──────────────────────────────────────────
  · 没反应 / 报错：多半是 Key 没填对，或网络没连到 Gemini。
  · 想改沈秣的性格：编辑 persona.js，重启（Ctrl+C 停，再 npm start）。
  · 想换模型：改 config.json 里的 "model"。
  · 备份：把 data 文件夹复制走就行，聊天记录都在里面。

  任何一步卡住，把 Termux 里的报错截图发我，我帮你看。
